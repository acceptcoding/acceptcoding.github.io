# ACCEPT local fonts

These WOFF2 assets are subsetted variable builds generated from the official
Google Fonts repository sources:

- [Roboto](https://github.com/google/fonts/blob/main/ofl/roboto/Roboto%5Bwdth,wght%5D.ttf)
- [Roboto Condensed](https://github.com/google/fonts/blob/main/ofl/robotocondensed/RobotoCondensed%5Bwght%5D.ttf)
- [Roboto Mono](https://github.com/google/fonts/blob/main/ofl/robotomono/RobotoMono%5Bwght%5D.ttf)

They contain the Latin and Latin-extended characters required by ACCEPT's
Portuguese, English, and Spanish interface, plus its UI punctuation. The
upstream fonts are licensed under the SIL Open Font License; the applicable
license text is retained in `OFL.txt`.
